# Install with React Router

Use React Router in **Framework Mode**, which provides route modules and data loading on top of Vite. You need a Node.js version supported by [React Router](https://reactrouter.com/start/framework/installation) and Vite; these instructions were checked with Node.js 24, React Router 8.4.0 and Vite 8.3.0.

## Prepare the application

Create a new framework project:

```bash
npx create-react-router@latest my-app
cd my-app
npm install
```

The default template includes Tailwind. For this **fresh starter**, remove its packages:

```bash
npm uninstall tailwindcss @tailwindcss/vite
```

In `vite.config.ts`, remove the `tailwindcss` import and `tailwindcss()` plugin. Keep the React Router plugin and the rest of the configuration. Replace `app/app.css` with the layer declaration below. Replace the starter home page with the foundation example in the final step, and remove the unused `app/welcome/` directory. In `app/root.tsx`, remove the template's utility `className` attributes and Google Fonts `links` export; preserve the document structure and error boundary.

These cleanup steps apply to the generated starter. For an existing application, follow the [existing-project workflow](/docs/agent-workflow#establish-the-environment-first) before removing dependencies or styles.

Install the package when the [public npm release is available](/docs/installation):

```bash
npm install @loamui/core
```

## Load the three primitives

LoamUI ships finished CSS containing its tokens, element styles and component styles. Serve that file unchanged: current CSS processors can reject some of its native syntax. The script below gives the file a content-hashed URL, so a package update cannot reuse stale CSS.

Create `scripts/sync-loamui-css.mjs`:

```js
import { createHash } from "node:crypto";
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);
const css = readFileSync(require.resolve("@loamui/core/styles.css"));
const hash = createHash("sha256").update(css).digest("hex").slice(0, 12);
const filename = `loamui-${hash}.css`;
mkdirSync("public", { recursive: true });
writeFileSync(`public/${filename}`, css);
writeFileSync("app/loamui-styles.ts", `export const loamuiStyles = "/${filename}";\n`);
```

Add these generated paths to `.gitignore`:

```text
/public/loamui-*.css
/app/loamui-styles.ts
```

Run the sync script before development and production builds. In an existing project, extend its commands rather than replacing other setup steps.

```json
{
  "scripts": {
    "dev": "node scripts/sync-loamui-css.mjs && react-router dev",
    "build": "node scripts/sync-loamui-css.mjs && react-router build",
    "start": "react-router-serve ./build/server/index.js"
  }
}
```

Replace the fresh starter's `app/app.css` with:

```css
@layer loamui.tokens, loamui.elements, loamui.components;
```

In `app/root.tsx`, keep the existing `app.css` import and add the generated URL:

```tsx
import "./app.css";
import { loamuiStyles } from "./loamui-styles";
```

Add the stylesheet link to the existing `Layout` function's head. Keep `Meta`, `Links`, `Scripts` and `ScrollRestoration`:

```tsx
<head>
  <meta charSet="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <Meta />
  <link rel="stylesheet" href={loamuiStyles} />
  <Links />
</head>
```

The generated URL assumes the app is hosted at `/`; prefix it with your configured base when deploying under a subpath. Import application and recipe CSS normally; do not also import `@loamui/core/styles.css` through Vite.

## Check your first interface

Copy the [foundation example](/docs/installation#2-check-the-foundation) into `app/routes/home.tsx` and put its CSS alongside it. Omit `"use client"`: this setup uses React Router's standard Framework Mode, without React Server Components. Add a page title with a `meta` export in the same route file:

```tsx
export function meta() {
  return [{ title: "Welcome to LoamUI" }];
}
```

```bash
npm run dev
```

Check the interface, then stop that server and run:

```bash
npm run build
npm start
```

The default template uses server rendering. For a static deployment, follow React Router's [SPA mode guide](https://reactrouter.com/how-to/spa), keeping the same stylesheet setup.

After upgrading LoamUI, restart development or rebuild. Then [add the agent skill](/docs/installation#3-add-the-agent-skill).
