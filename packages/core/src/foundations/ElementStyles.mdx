# Element styles

The second primitive: enhanced default styles for native elements themselves,
applied page-wide by the `loamui.elements` layer. Importing the stylesheet opts
you in, so plain HTML is styled before any component appears; most of a new
component's CSS is already written before its stylesheet exists.

Everything below is bare markup, no classes.

## Typography

Headings use `--loam-font-display` at the fluid type scale, with balanced
wrapping and the strong text tier (`--loam-color-fg-strong`), a step darker
than body in light, brighter in dark. Body copy rides the same fluid scale
(`--loam-text-md`). Line-height is derived per element from its own size:

```css
line-height: calc(0.5rem + 2ex);
```

Running text gets common ligatures and old-style figures; headings get lining
figures; punctuation hangs, and long words hyphenate automatically. Margins are
additive: blocks carry only a block-end margin, and extra space before a
heading comes from an adjacent-sibling rule, so nothing needs unsetting at a
container's top edge.

## Forms without components

Native form controls wear the component recipes automatically: bare `<button>`
elements get the Button anatomy on the neutral text channel (raised at rest,
settling when pressed, because raised means pressable); textual inputs get the
Input field look; checkboxes, radios, ranges and progress bars are native
`accent-color` controls driven by the neutral primary. The React components
remain the upgrade path (fluid sizing, context adaptation, and field wiring),
but a plain form is styled and usable on its own.

## Focus, selection and details

One shared `:focus-visible` ring, offset so the page shows through the gap; it
survives forced colours and follows each control's border radius. Text selection
uses the highlight token; the caret and form `accent-color` take the neutral
primary. Anything with an `id` gets scroll margin so anchored headings don't hide
under sticky chrome, and the page reserves its scrollbar gutter so content
doesn't jump.

## A floor, not a ceiling

The elements layer is the lowest of the three, so your own unlayered CSS always
wins and a component's own parts win for that component. Restyle an element
globally with a single rule:

```css
/* Your unlayered CSS always beats the elements layer */
blockquote {
  border-inline-start-color: var(--loam-color-primary);
}
```
